Five directions for the SQaLe website

Each mockup is a complete one-page site with the same content: the paper's numbers, one real record from the test set, the pipeline, the controlled comparison and the three findings. Only the design differs. All five read their charts from assets/sqale-data.js and support light and dark mode.

To Scale

A Swiss poster that takes the name literally: every comparison is drawn to scale. The median schema appears as one square per table (5 for BIRD, 113 for SQaLe), and compute appears as circles with area proportional to TFLOPs.
